# Website Dividers

Horizontal rules and micro-dividers: lines, whitespace, card edges and partial-width accents.
Click any snippet to copy it, in plain CSS, Tailwind, Bootstrap, React, Vue or Svelte.

> Early work in progress: the catalog and its snippets are still being built.

## Use it

The whole site is one static file, `index.html`, with no build step and no dependencies beyond
Google Fonts. Open it in a browser, or serve the folder with any static server:

```bash
npx serve .
```

Browse dividers by category, search them, switch the code format, and toggle light/dark mode.
